# STATS19 Bronze Layer

This folder contains the raw STATS19 road safety datasets from the UK Department for Transport.

## Structure

- raw/collisions: raw collision data
- raw/vehicles: raw vehicle data
- raw/casualties: raw casualty data
- reference: official STATS19 data guide
- metadata: ingestion metadata generated by the ingestion script

The raw files are preserved without modification.

The ingestion script checks that the required files exist and are not empty, then records metadata about the ingestion.
